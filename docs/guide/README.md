# Документация кода «Подбор вакансий»

Здесь подробно объяснено, как устроен код приложения: что делает каждый модуль и каждая функция,
как вакансия проходит путь от сайта до строки в таблице и почему код написан именно так.

Это описание **того, что реально написано** (состояние на 2026-10-13, ветка `job-finder`).
Спецификация [docs/superpowers/specs/2026-10-13-job-finder-design.md](../superpowers/specs/2026-10-13-job-finder-design.md)
описывает, *что решили сделать*. Если код где-то расходится со спецификацией, это отмечено
в разделе [«Ограничения»](10-howto-and-limits.md#известные-ограничения-и-расхождения).

Ссылки вида [llm.py:92](../../job_finder/llm.py#L92) ведут прямо на строку кода.
В VS Code откройте превью Markdown (`Ctrl+Shift+V`) и кликайте по ссылкам.

## Словарик

| Термин | Что значит в этом коде |
|---|---|
| **Вакансия, `Job`** | Единая запись о вакансии из любого источника: `url`, `source`, `title`, `company`, `city`, `published`, `description`. Класс — [sources.py:19](../../job_finder/sources.py#L19). |
| **Источник** | Один из четырёх сайтов-агрегаторов с открытым API: junior.guru, Himalayas, Jobicy, Working Nomads. |
| **Отсев по навыкам** | Быстрая проверка без ИИ: встречается ли в вакансии хоть один навык из раздела `## Skills` резюме. Не прошла — модель её не оценивает. |
| **Оценка** | Ответ модели в виде JSON: `score` (1–10), `summary`, `have`, `missing`, `risks`. |
| **Ключ оценки** (`cv_hash`) | SHA-256 от текста резюме + названия модели + правил оценки. Хранится рядом с оценкой. Если ключ изменился — все оценки считаются устаревшими. |
| **Порог** (`MIN_SCORE`) | Минимальная оценка, при которой вакансия показывается в таблице. Сейчас 5. |
| **Активная** (`active = 1`) | Вакансия была в последней успешной выдаче своего источника. |
| **Скрытая** (`hidden = 1`) | Пользователь нажал «Скрыть». Больше не показывается и не оценивается. |
| **Очередь** | Активные нескрытые вакансии без оценки по текущему ключу. |
| **LM Studio** | Программа для запуска языковых моделей на своём компьютере. У неё есть консольная утилита `lms.exe` и HTTP-сервер, совместимый с OpenAI API. |
| **Идентификатор модели** (`job-finder`) | Имя, под которым наша модель загружена в LM Studio и по которому к ней обращается API. |
| **Сигнал / слот** | Механизм Qt: объект «испускает» сигнал, подключённые функции (слоты) вызываются. Через сигналы фоновый поток передаёт результаты окну. |
| **Цикл событий** | Бесконечный цикл Qt (`app.exec()`), который обрабатывает клики, перерисовку, таймеры и сигналы из других потоков. |
