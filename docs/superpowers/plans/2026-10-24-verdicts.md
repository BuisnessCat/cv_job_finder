# Verdicts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** The model extracts facts from an ad; the program compares them with a profile and gives a verdict
(Strong fit / Worth a try / Stretch / Out of reach / Other area) shown in card variant A.

**Architecture:** `llm.SCHEMA` and `RULES_TEMPLATE` ask for facts only; `grounding.verdict(extraction, job, known, s)`
computes the conditions, skills and verdict; the evaluation stores the extraction, so `worker.recount(s)` redoes the
verdicts after a Settings change without the model. The card gets a verdict band, a conditions grid and chips.

**Spec:** `docs/superpowers/specs/2026-10-13-job-finder-design.md`, section 21.

## Global Constraints
- English UI and code, no Cyrillic in `job_finder/`, `tests/`.
- No lambdas holding `self` in signal connections.
- Tests never call the real model, network or `busy.windows_busy`.
- `config.VERSION = "1.4.0"`.

## Review Focus
1. An ad that says "MSc preferred" must not rule out a student (degree only when required, and its word in the ad).
2. "Junior … (Mid/Senior welcome)" titles: a junior candidate is not ruled out by "Senior" in a parenthesis.
3. Settings saved during a pass: verdicts of the jobs still to be scored use the new profile.
4. Old evaluations (applications) still render in the card.
5. A Czech ad: "v Pythonu", "praxe 3 roky", "VŠ vzdělání" are understood.

### Task 1: Profile in the settings, the wizard and Settings
Files: `settings.py`, `settings_window.py`; tests `test_settings.py`, `test_settings_window.py`.
Produces `Settings.education/experience/areas`, `EDUCATION`, `EXPERIENCE`, `AREAS`, `guess_areas(skills)`,
`SCORING_FIELDS = ("cv_path",)`, `PROFILE_FIELDS`.

### Task 2: Facts from the model, the verdict from the program
Files: `llm.py`, `grounding.py`; tests `test_llm.py`, `test_grounding.py`.
Produces `grounding.verdict(extraction, job, known, s) -> dict` (verdict, score, reason, conditions, must, nice,
about, have, missing, risks, extraction).

### Task 3: Scoring saves the facts; Settings recount without the model
Files: `worker.py`, `window.py`, `db.py`; tests `test_worker.py`, `test_window.py`.
Produces `worker.recount(s) -> int`, window recount after a profile change, search restart for city/remote/levels.

### Task 4: Card variant A
Files: `window.py`, `style.py`; tests `test_window.py`. Real-window screenshot.

### Task 5: Docs, version, before/after
README, how-it-works, version 1.4.0; the sample with the real model.
