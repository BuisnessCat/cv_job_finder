# Вкладка Insights — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** третья вкладка главного окна показывает, каких требований вакансий чаще всего не хватает и
что чаще всего требуют, по разборам модели всех оценённых вакансий.

**Architecture:** чистый модуль `insights.py` (словарь требований `REQUIREMENTS`, `find()`,
`analyze()`) считает по спискам `have` / `missing`; `db.evaluations()` отдаёт разборы той же выборки,
что «Done: … evaluated»; `skills.skill_lines()` — общий разбор раздела Skills для отсева и для
пометки «есть в резюме»; окно получает третью кнопку переключателя и страницу с двумя карточками полос.

**Tech Stack:** Python 3.11, PySide6, SQLite, pytest.

**Spec:** `docs/superpowers/specs/2026-10-13-job-finder-design.md`, раздел 13 (обязательный), разделы 4,
6, 7 — поведение, на которое он опирается.

## Global Constraints

- Надписи — ровно как в разделе 13 спека: «Insights», «MOST OFTEN MISSING», «In how many jobs the model
  listed it under Missing», «MOST OFTEN REQUIRED», «Green: counted as yours · red: missing»,
  «Based on N evaluated jobs · U missing items not recognised», «No master_cv.md — nothing to analyse»,
  «Nothing evaluated yet».
- Совпадение требования — `(?<![\w#+.])(?:варианты)(?![\w#+])`, без учёта регистра.
- По 20 строк в каждом списке; самая длинная полоса — 220 px.
- В `job_finder/*.py`, `tests/*.py`, `install.ps1` — без кириллицы (тест `tests/test_english.py`).
- `docs/guide/` — по-русски; ссылки на строки проверяются скриптом.
- Модель не вызывается; тесты не трогают настоящие `master_cv.md` и `jobs.db`.
- Команда тестов: `.venv/Scripts/python -m pytest tests -q`.
- Коммит заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Файлы с регулярными выражениями писать инструментом Write/Edit, без `\b`, `\n`, `\t`, `\u`, `\/` в
  тексте (инструменты превращают их в символы); границы слова — через lookbehind/lookahead.

## Review Focus

1. Короткие варианты, похожие на обычные слова (`go`, `r`, `c`, `ai`, `rest`, `master`, `solid`), не
   должны давать ложных совпадений («go-to-market», «R&D», «Scrum Master», «solid understanding») —
   тест в задаче 1.

4. Обновление закончилось, пока открыта вкладка: цифры пересчитаны; на другой вкладке вид не

В `job_finder/skills.py` заменить `load_skills` на пару функций (поведение `load_skills` не меняется):

```python
def skill_lines(cv_text: str) -> list[str]:
    """Items of the "## Skills" section that count as skills: "- " lines without Concepts and In progress."""
    lines = []
    in_skills = False
    for line in cv_text.splitlines():
        if line.startswith("## "):
            in_skills = line.startswith("## Skills")
            continue
        if in_skills and line.startswith("- ") and not line[2:].startswith(("Concepts", "In progress")):
            lines.append(line[2:])
    return lines


def load_skills(cv_text: str) -> list[str]:
    """Skills from the "## Skills" section: line part before " — ", split by commas, first word of each."""
    skills = []
    for item in skill_lines(cv_text):
        for part in item.split(" — ")[0].split(","):
            words = part.split()
            if words:
                skills.append(words[0])
    return skills
```

```python
_PATTERNS = {name: re.compile(r"(?<![\w#+.])(?:" + "|".join(aliases) + r")(?![\w#+])", re.IGNORECASE)
             for name, aliases in REQUIREMENTS.items()}


def find(text: str) -> set[str]:
    """Requirements mentioned in a text."""
    return {name for name, pattern in _PATTERNS.items() if pattern.search(text)}


@dataclass
class Insights:
    total: int                            # evaluated jobs counted
    missing: list[tuple[str, int]]        # (requirement, jobs where the model listed it under Missing)
    required: list[tuple[str, int, int]]  # (requirement, jobs that ask for it, of them counted as yours)
    in_cv: set[str]                       # requirements found in the CV Skills section
    unknown: int                          # "missing" items that match no requirement


def _top(counter: Counter) -> list[tuple[str, int]]:
    """Most frequent first, ties by name; the first TOP."""
    return sorted(counter.items(), key=lambda item: (-item[1], item[0]))[:TOP]


def analyze(evaluations: list[dict], cv_skill_lines: list[str]) -> Insights:
    """Count requirements over the model's have / missing lists; each job gives a requirement at most one point."""
    in_cv = set().union(*(find(line) for line in cv_skill_lines))
    missing, required, yours = Counter(), Counter(), Counter()
    unknown = 0
    for evaluation in evaluations:
        lacking = set()
        for item in evaluation.get("missing") or []:
            found = find(item)
            lacking |= found
            unknown += not found
        having = set().union(*(find(item) for item in evaluation.get("have") or []))
        missing.update(lacking - in_cv)  # what the CV already lists is a lack of experience, not a gap
        required.update(lacking | having)
        yours.update(having)
    return Insights(total=len(evaluations), missing=_top(missing),
                    required=[(name, count, yours[name]) for name, count in _top(required)],
                    in_cv=in_cv, unknown=unknown)
```

```python
def _bar_row(name: str, count: int, yours: int, scale: int, mine: bool = False) -> QWidget:
    """Insights row: name, a bar (green part counted as yours, red part missing) and the number of jobs."""
    row = QWidget()
    line = QHBoxLayout(row)
    line.setContentsMargins(0, 0, 0, 0)
    line.setSpacing(10)
    label = QLabel(("✓ " if mine else "") + name)
    label.setObjectName("barName")
    label.setFixedWidth(180)
    if mine:
        label.setStyleSheet(f"color: {style.LIST_COLORS['have']};")
    track = QFrame()
    track.setFixedSize(max(2, round(BAR_WIDTH * count / scale)), 10)
    parts = QHBoxLayout(track)
    parts.setContentsMargins(0, 0, 0, 0)
    parts.setSpacing(0)
    for color, size in ((style.LIST_COLORS["have"], yours), (style.LIST_COLORS["missing"], count - yours)):
        if size > 0:
            part = QFrame()
            part.setStyleSheet(f"background: {color}; border-radius: 3px;")
            parts.addWidget(part, size)
    number = QLabel(str(count))
    number.setObjectName("barCount")
    line.addWidget(label)
    line.addWidget(track)
    line.addWidget(number)
    line.addStretch(1)
    return row
```

```python
    def render_insights(self) -> None:
        """Recount the Insights tab from the analyses of all evaluated jobs (spec section 13)."""
        cv = read_cv()
        evaluations = db.evaluations(cv[1]) if cv else []
        message = ("No master_cv.md — nothing to analyse" if cv is None
                   else "Nothing evaluated yet" if not evaluations else "")
        self.insights_message.setText(message)
        self.insights_message.setVisible(bool(message))
        self.insights_cards.setVisible(not message)
        self.insights_note.setVisible(not message)
        if message:
            return
        result = insights.analyze(evaluations, skills.skill_lines(cv[0]))
        lists = [(self.missing_rows, [(name, count, 0) for name, count in result.missing], set()),
                 (self.required_rows, result.required, result.in_cv)]
        for rows, items, mine in lists:
            while rows.count():
                rows.takeAt(0).widget().setParent(None)  # remove now, not after deleteLater
            scale = max((count for _, count, _ in items), default=1)
            for name, count, yours in items:
                rows.addWidget(_bar_row(name, count, yours, scale, name in mine))
            if not items:
                empty = _label("muted")
                empty.setText("—")
                rows.addWidget(empty)
        jobs = "job" if result.total == 1 else "jobs"
        items = "item" if result.unknown == 1 else "items"
        self.insights_note.setText(f"Based on {result.total} evaluated {jobs} · {result.unknown} missing {items}"
                                   " not recognised")
```

```python
"""Share of the model's "missing" items that the requirement dictionary recognises, on the real database."""
import collections
import json
import os
import sqlite3
import sys

sys.path.insert(0, os.getcwd())
from job_finder import insights, skills, worker

cv_text, key = worker.read_cv()
conn = sqlite3.connect("file:jobs.db?mode=ro", uri=True)
rows = conn.execute("SELECT evaluation FROM jobs WHERE active = 1 AND hidden = 0 AND status IS NULL AND cv_hash = ?",
                    (key,)).fetchall()
evaluations = [json.loads(r[0]) for r in rows]
items = [item for e in evaluations for item in e.get("missing") or []]
unknown = collections.Counter(i.lower() for i in items if not insights.find(i))
result = insights.analyze(evaluations, skills.skill_lines(cv_text))
print(f"jobs {result.total}; missing items {len(items)}; recognised {1 - result.unknown / len(items):.0%}")
print("missing:", result.missing)
print("required:", result.required)
print("in CV:", sorted(result.in_cv))
print("unknown sample:", [p for p, _ in unknown.most_common(30)])
```
