# Настройки и мастер первого запуска — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** приложение больше не сшито под автора: всё личное (резюме, навыки, город, профессия, уровень,
языки, разрешение на работу, пороги) живёт в настройках, которые заполняются мастером при первом запуске и
меняются в окне Settings; правила оценки нейтральны и собираются из настроек.

**Architecture:** новый модуль `job_finder/settings.py` (класс `Settings`, хранение в таблице `settings`
базы, чтение резюме из `.md`/`.txt`/`.pdf`, поиск навыков словарём Insights); `llm.render_rules(s)` собирает
правила из шаблона; воркер, источники и окно берут значения из `Settings` вместо `config.py`; новый модуль
`job_finder/settings_window.py` — общая форма, мастер и окно Settings. Мастер запускает `__main__`, а не
`MainWindow`, поэтому окно и его тесты от мастера не зависят.

**Tech Stack:** Python 3.11, PySide6, SQLite, `pypdf` (новая зависимость), pytest.

**Spec:** `docs/superpowers/specs/2026-10-13-job-finder-design.md`, раздел 15 (обязательный).

## Global Constraints

- Поля и значения по умолчанию — ровно как в таблице 15.1; города — список регионов junior.guru из 15.1;
  уровни языка — `none, A1, A2, B1, B2, C1, C2`; `level` — `junior` | `mid`; ключевых слов 1–3.
- Обязательные: резюме, хотя бы один навык, 1–3 ключевых слова, английский, чешский, разрешение на работу.
- Влияют на оценку (вопрос о переоценке): резюме, город, удалёнка, уровень, английский, чешский,
  разрешение. Не влияют: навыки, ключевые слова, порог, сроки.
- Надписи: «Welcome», «Your CV», «What you're looking for», «About you», «Back», «Next», «Start search»,
  «Remote is fine», «Your level», «I need a work permit for Czechia», «Settings», «Save», «Cancel»,
  «All jobs will be scored again (about N min). Save?».
- В коде нет значений автора (Praha, python, B2, B1, «разрешение не нужно» — только в скрипте проверки
  задачи 4 вне репозитория). `Praha` как город по умолчанию для нового пользователя — из спека, это не
  значение автора.
- В `job_finder/*.py`, `tests/*.py` — без кириллицы; тесты не трогают настоящие `jobs.db` и `master_cv.md`.
- Команда тестов: `.venv/Scripts/python -m pytest tests -q`.
- Коммит заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Резюме, которое нельзя прочитать (битый PDF, PDF-картинка без текста, файл удалён после настройки):
   понятное сообщение, приложение не падает, обновление не оценивает — тест в задаче 1 и 2.
2. Навык, введённый вручную и отсутствующий в словаре (например, `Kotlin Multiplatform`, `1C`): отсев
   ищет его целым словом, Insights не падает — тест в задаче 2.
3. Без удалёнки старые удалённые вакансии исчезают из Found и не оцениваются заново — тест в задаче 3.
4. Отмена в окне Settings или «Cancel» на вопросе о переоценке ничего не меняет — тест в задаче 5.
5. Закрытие мастера крестиком на любом шаге не сохраняет настройки и закрывает приложение — тест в задаче 5.

**Interfaces:**
- Produces:
  - `@dataclass Settings(cv_path: str = "", skills: list[str] = [], city: str = "Praha", remote: bool = True,
    keywords: list[str] = [], level: str = "junior", english: str = "", czech: str = "",
    needs_permit: bool | None = None, min_score: int = 5, stale_days: int = 14, stale_job_days: int = 21)`
    (списки — через `field(default_factory=list)`);
  - `CITIES: list[str]` (13 регионов из 15.1, первым `Praha`), `LEVELS = ["junior", "mid"]`,
    `LANGUAGE_LEVELS = ["none", "A1", "A2", "B1", "B2", "C1", "C2"]`,
    `SCORING_FIELDS = ("cv_path", "city", "remote", "level", "english", "czech", "needs_permit")`;
  - `load() -> Settings | None`, `save(s: Settings) -> None` (JSON в `db.get_settings() -> dict | None` /
    `db.put_settings(data: dict) -> None`, таблица `settings(id INTEGER PRIMARY KEY CHECK (id = 1), data TEXT)`);
  - `missing(s: Settings) -> list[str]` — имена незаполненных обязательных полей в порядке
    `cv_path, skills, keywords, english, czech, needs_permit`;
  - `scoring_changed(old: Settings, new: Settings) -> bool`;
  - `class CvError(Exception)`, `read_cv_text(path: str) -> str` (`.md`/`.txt` — UTF-8 с `errors="replace"`,
    `.pdf` — текст страниц через `pypdf`; нет файла / не читается / пустой текст → `CvError` с понятным
    сообщением на английском);
  - `detect_skills(text: str) -> list[str]` — `insights.find(text)` без групп `Experience 2+ years`,
    `Czech`, `German`, `Other languages`, `English C1+`, `Degree`, `Domain knowledge`, `Soft skills`,
    `Project management`, в порядке `insights.REQUIREMENTS`;
  - `initial(cv: Path) -> Settings` — если файл есть: `cv_path` = он, `skills` = `detect_skills`; иначе пустые;
  - `tests/helpers.py`: `use_settings(cv: Path, text: str = "Python developer", **overrides) -> Settings` —
    пишет файл резюме, если его нет, сохраняет заполненные настройки (`skills=["Python"]`, `keywords=["python"]`,
    `english="B2"`, `czech="none"`, `needs_permit=False`, остальное по умолчанию или из `overrides`) в текущую
    `config.DB_PATH` и возвращает их.

- Produces:
  - `llm.RULES_TEMPLATE: str`, `llm.render_rules(s: Settings) -> str`, `llm.fingerprint(s: Settings) -> str`
    (модель + готовые правила), `llm.evaluate(cv_text: str, job: Job, rules: str) -> dict`;
  - `worker.read_cv(s: Settings | None) -> tuple[str, str] | None` (текст и ключ; `None` без настроек или при
    `CvError`); `Worker._refresh` берёт настройки один раз в начале;
  - `skills.matches(job: Job, skills: list[str]) -> bool` — навык из словаря ищется шаблоном

Нейтральные правила — по 15.5: «You help a candidate…»; блокер «the job's main programming language or field
differs from the candidate's main one in the CV»; близкие навыки — общим правилом с примерами (Django ≈
FastAPI, MySQL ≈ PostgreSQL, React ≈ Vue, Spring ≈ Jakarta EE); `level` — тексты блокеров и верхней полосы
шкалы из 15.5; языки — «The candidate's English: B2; Czech: none» и блокер «a required language level above
the candidate's»; разрешение — `needs_permit=False`: «does not need a work permit for Czechia (not a
problem)», `True`: «needs a work permit for Czechia; a job that cannot sponsor one is a blocker»; удалёнка —
`True`: офис/гибрид в городе и удалёнка из Чехии/ЕС — не проблема, `False`: «wants office or hybrid work in
<city>; remote-only jobs are not a fit». Последняя строка — по-прежнему «Candidate's CV:».
